# おめで島ぐらし

さいけうとゆいちゃんの沖縄5泊6日誕生日旅行、ふたりだけのサイト。


## 保存先（Supabase）の設定
- `supabase_setup.sql` を Supabase の SQL Editor で一度実行すると、保存用の表・写真の保存場所・ふたりだけの許可・リアルタイム更新がそろいます（何度実行しても壊れません）。
- サイト下部の「せつぞくチェック」で、どこまで設定できているかを確認できます。保存に失敗したときも自動でこの画面がひらきます。

## 編集について
- `index.html` がこのサイトの唯一のソースです（CSS・JS・データすべて入り）。ここを直接編集してコミットすると GitHub Actions が公開します。
- 地図：`ISLANDS`（海岸線のSVGパス、10単位=1km）、`COORDS`（既定の行き先の緯度経度）、`REGIONS`・`LANDMARKS`・`EXPRESSWAY`・`ROUTE58`。編集画面で「地図で検索する名前」を入れて保存すると Nominatim（OpenStreetMap）で座標を自動取得します。

## 旅行中の機能
- 当日モード：旅行中は「しおり」のいちばん上に、その日の予定・いまの時刻・つぎの予定までの時間・ナビ（Googleマップ）・天気・クイックボタンが出ます。旅行前は「当日モードをためす」で見られます。
- 天気：Open-Meteo（best_match・気象庁JMA・ECMWF・GFS・ICON の各モデル）、Open-Meteo Marine（波）、気象庁（府県天気予報・週間予報の信頼度・注意報警報・概況）、雨雲（気象庁 高解像度降水ナウキャスト、取れないときは RainViewer）を直接取得し、サイト内で見比べられます。30分キャッシュ。
- こんぺきのお願い：ガチャの2回目・3回目に、こんぺきからのお願いがまざって出ます。クリアすると「こんぺき→ゆいちゃん」のなつき度が上がります。
- 今日の一枚：写真をひらいて「今日の一枚にする」。アルバムの日ごとの先頭・思い出ムービー・リザルトに出ます（ひとことも書けます）。
- 旅の軌跡マップ：アルバムの「軌跡マップ」で、写真の撮影場所（EXIFのGPS。ないものはスタンプの場所や予定から推定）を日ごとの色でつないで表示。保存する画像からはEXIFを取り除き、座標と撮影時刻だけを `photos` の記録に残します。
- 着せ替え：`COS`（約45種のSVGアイテム）と `RULES` で、その日の予定・いまの行き先・時間帯・天気（雨・紫外線）・誕生日に合わせて3人の衣装が自動で変わります。位置は `COS_ANCHOR`（体の箱に対する％）で調整します。

## 背景の3Dシーン
- `tools/hero-scene.html` が島の背景（three.js で描いたトイ風のジオラマ）の元データです。`npm i three` した場所で `tools/hero-capture.py` を実行すると `back / foam / front / water` の各レイヤーを書き出せます（`water` は海のマスク用）。
